### What I Learned

    -- <@pytest.mark.parametrize("joint,target", VALID_JOINTS)>

       ● @pytest.mark.parametrize

          This decorator tells pytest to execute the same test function multiple times, using different test inputs.

       ● name of the test parameter

       ● VALID_JOINTS
         
         the list of test cases

      pytest will run "test_three_joints_with_different_proportional_gain" three times
